Architecture guide and editable sequence/deployment diagrams

Two identity flows

Member identity uses OIDC and a cookie session. SharePoint access uses a separate application token. PHP must enforce membership and action capabilities before exposing data or writing lists.

Deployment constraint

Static hosting alone is insufficient. Vite preview does not execute PHP. Compose currently serves the development backend, not a built production frontend.

Build safety warning

The current Vite plugin embeds PHP env-file values and the build process environment into emitted PHP. Build in an isolated minimal environment and treat output as sensitive.
